# Dangorobo 0.9.1

바탕화면 한쪽에 사는 로우폴리 고양이입니다. 마우스를 따라 보고, 타이핑에 맞춰 꼬리를 흔들고,
쓰다듬으면 좋아하고, 정해둔 시간에 알람을 알려줍니다. 원하면 대화도 할 수 있습니다.

평소에는 클릭이 그대로 통과되니 작업을 방해하지 않습니다. Windows 전용이고, 설치 없이 실행 파일 하나로 씁니다.

## 처음 시작하기

1. 실행하면 화면 구석에 고양이가 나타나고, 작업 표시줄 알림 영역에 아이콘이 생깁니다.
2. 펫이나 트레이 아이콘을 **우클릭**하면 메뉴가 열립니다. 여기서 설정창을 열 수 있습니다.
3. 펫은 **그냥 드래그해서** 원하는 자리로 옮기면 됩니다. 위치는 다음 실행에도 유지됩니다.
4. 종료는 우클릭 메뉴 또는 `Ctrl + Shift + Q`입니다.

한국어·영어·일본어를 지원하며 처음 실행할 때 Windows 언어에 맞춰 자동으로 선택됩니다.

설치본(`Dangorobo-Setup.exe`)으로 설치했다면 새 버전이 나왔을 때 자동으로 내려받고, 재시작해서
설치할지 물어봅니다. portable 버전(`Dangorobo-Portable.exe`)은 자동 업데이트 확인을 하지
않으므로 새 버전을 직접 받아야 합니다.

## 펫의 반응

- **마우스를 따라 봅니다.** 커서 방향으로 고개를 돌립니다.
- **타이핑에 반응합니다.** 빠르게 칠수록 꼬리가 크고 빠르게 흔들립니다. 무엇을 쳤는지는 읽지 않고 얼마나 자주 쳤는지만 봅니다.
- **클릭·키 입력마다 살짝 눌립니다.** 젤리처럼 출렁이고, 원하면 클릭할 때 소리도 낼 수 있습니다(기본 꺼짐).
- **머리를 쓰다듬어 보세요.** 머리 위에서 마우스를 좌우로 문지르면 기뻐하며 고개를 숙입니다.
- **들어올리면 놀랍니다.** 드래그하는 동안 허우적거립니다.
- **혼자 있으면 잠듭니다.** 아무 입력이 없으면(기본 5분) 눈을 감고 졸다가, 다시 움직이면 깨어납니다.
- **가만히 두면 심심해합니다.** 둘러보기, 스트레칭, 손 흔들기 같은 동작을 이따금 혼자 합니다.
- **Caps Lock이 켜져 있으면** 알려줍니다(얼굴이 놀란 표정으로 떨립니다).
- **게임이나 발표 중에는 알아서 숨습니다.** 전체화면 프로그램을 감지해 펫과 알람을 잠시 치웁니다(켜야 동작).

## 꾸미기

설정창 **커스터마이징** 탭에서 바꿉니다. 고르는 즉시 펫에 반영되고, 저장하지 않고 닫으면 되돌아갑니다.

- **색**: 머리·몸통·귀·꼬리·손·머리 장식·눈·입·얼굴 무늬·얼굴 장식·몸 무늬를 부위별로 따로 칠할 수 있습니다.
- **파츠**: 귀 5종(곰·토끼·고양이·여우·처진), 꼬리 3종, 머리 장식 8종(리본·초커·안경·모자·헤일로 등). 전부 "없음"도 고를 수 있습니다.
- **얼굴**: 눈·입 모양과 얼굴 무늬·장식을 조합합니다. 표정은 상황에 따라 알아서 바뀝니다.
- **내 얼굴 그림 넣기**: 직접 그린 표정 이미지들을 zip으로 묶어 불러오면 눈·입 대신 그 그림이 나옵니다.
- **펫 주변에서 색 고르기**: 이름만 보고 고르기 어려우면 이 모드를 켜세요. 펫 옆에 부위별 색 카드가 실제 위치와 선으로 이어져 떠서, 보면서 바로 고를 수 있습니다.
- **프리셋**: 마음에 드는 조합을 이름 붙여 저장해두고 나중에 한 번에 적용합니다. 미리보기 썸네일이 보이고, 파일로 내보내 다른 PC에서 불러올 수도 있습니다. (기본으로 체리·미로·로로 3종이 들어 있습니다)

## 화면 효과

설정창 **외형** 탭에서 조절합니다. 마음에 안 들면 "외형 기본값으로 초기화" 버튼으로 한 번에 되돌릴 수 있습니다.

- **크기와 꼬리 속도** 조절
- **픽셀 아트**: 강도를 올리면 도트 그림처럼 거칠어집니다.
- **색 단계 제한**: 쓰는 색 수를 줄여 레트로 느낌을 냅니다. 따뜻함·차가움·흑백·게임보이풍 중에서 고르거나, 원하는 색들로 직접 그라디언트를 만들 수 있습니다.
- **디더링**: 색 경계를 옛 게임처럼 점 무늬로 흩뿌립니다(8종).
- **외곽선**: 실루엣에 테두리를 그립니다. 색과 굵기 조절.
- **선 떨림**: 손그림 애니메이션처럼 윤곽선이 미세하게 흔들립니다.
- **조명**: 빛의 색·세기·방향을 직접 만질 수 있습니다.

## 알람

설정창 **알람** 탭에서 여러 개를 등록할 수 있습니다.

- **반복 방식 4가지**: `N분마다` / `정시마다`(매 정각, 몇 시간마다인지 지정 가능) /
  `매일 정해진 시각`(요일 지정 가능) / `몇 분 뒤 한 번만`
- `정시마다`는 등록한 시각과 상관없이 **시계의 정각(분·초 0)**에 맞춰 울립니다.
- 알람마다 **제목과 내용**을 따로 적을 수 있습니다.
- 지우지 않고 **잠깐 껐다 켜기**, 나중에 **내용 수정**도 됩니다.
- 시간이 되면 펫이 만세하며 알려주고, 확인을 누를 때까지 기다립니다.
- 알림 소리는 5종 중에서 고르거나, **알람마다 원하는 mp3·wav 파일**을 지정할 수 있습니다.
- "지금 알람 테스트" 버튼으로 어떻게 보이는지 미리 확인하세요.
- 다음 알람까지 남은 시간은 우클릭 메뉴에서 볼 수 있습니다.
- **날씨 브리핑**: `매일 정해진 시각` 알람에서 "날씨 브리핑 포함"을 켜면, 울릴 때 내용이
  오늘·내일 오전/오후 날씨(4줄, 최고·최저·강수확률)로 자동 채워집니다("일반" 탭에서 지역을
  먼저 입력하세요). 회원가입이 필요 없는 Open-Meteo로 조회하며, 대한민국 지역은 기상청(KMA)
  데이터를 우선 씁니다. 트레이 메뉴의 **현재 날씨**로 언제든 바로 확인할 수도 있습니다
  (트레이 탭에서 켜고 끌 수 있음).

## 오늘 할일 체크리스트

`Ctrl + Shift + T`로 여는 작은 창입니다.

- 할 일을 적고 체크하면 **펫이 축하해줍니다.**
- 드래그로 순서를 바꾸고, 남은 개수가 배지로 표시됩니다.
- 창은 원하는 자리에 두고 크기를 바꿀 수 있으며, 껐다 켜도 그대로 복원됩니다.

## 즐겨찾기 실행기

자주 쓰는 프로그램을 펫에서 바로 실행합니다. 프로그램·바로가기·웹 링크를 최대 12개 등록할 수 있고, 기본 단축키는 `Ctrl + Shift + F`입니다.

**어디에 띄울지 4가지 중에서 고릅니다.**

| 방식 | 이렇게 뜹니다 |
|---|---|
| 펫 말풍선 | 펫 머리 위에 목록이 뜹니다 (기본) |
| 이동 가능한 창 | 원하는 자리에 두는 작은 창 |
| 플로팅 버튼 | 화면에 늘 떠 있는 동그란 버튼, 누르면 부채꼴로 펼쳐집니다 |
| 마우스 위치에 열기 | 단축키를 누른 그 자리에 부채꼴 메뉴가 뜹니다 |

아이콘은 프로그램에서 자동으로 가져오고, 마음에 안 들면 내장 아이콘 18종 중에서 골라 색까지 지정하거나 직접 이미지 파일을 넣을 수 있습니다. 목록형·격자형 중에서 보기 방식도 선택합니다.

## 펫과 대화하기

Google의 Gemini를 씁니다. **무료 API 키를 직접 발급해 넣어야** 쓸 수 있고, 기본은 꺼져 있습니다.

1. 설정창 **일반** 탭에서 API 키를 입력합니다(발급 페이지 링크가 옆에 있습니다).
2. 대화 기능을 켜고 저장합니다.
3. `Ctrl + Shift + A` 또는 우클릭 메뉴로 대화창을 엽니다.

- **성격을 고를 수 있습니다**: 편한 친구, 친근한 존댓말, 담백한 조언자, 가벼운 장난꾸러기, 또는 직접 한 줄로 지정.
- **부르는 이름**: 펫이 나를 어떻게 부를지, 자기를 뭐라고 할지 정할 수 있습니다.
- 답변에 맞춰 **표정이 바뀌고** 말하는 동안 고개를 끄덕입니다.
- 질문한 언어로 답합니다.
- **펫이 먼저 말을 걸게** 할 수도 있습니다(3~20분 간격). 머리를 한참 쓰다듬으면 반응해서 말을 걸게 하거나, "부르기" 버튼으로 바로 부를 수도 있습니다.
- **대화 효과음**: 답변이 한 글자씩 나오면서 글자마다 소리가 납니다. 속도와 음높이를 조절할 수 있습니다.
- **기억하기**: 켜두면 이전 대화를 이어서 기억하고, 취향·습관 같은 것도 조금씩 기억합니다. 무엇을 기억하고 있는지는 "대화" 탭의 "'기억 관리' 탭 표시(고급 사용자 전용)"를 켜면 나타나는 **기억 관리** 탭에서 직접 보고 지울 수 있습니다.
- 주고받은 내용은 우클릭 메뉴의 **질문·답변 기록**에서 검색하고 지울 수 있습니다.

API 키는 Windows 보안 저장소에 암호화해서 보관하며, 설정 백업 파일에도 대화 기록에도 들어가지 않습니다.

## 편리한 도구들

- **문서 요약** (`Ctrl + Shift + D`) — 긴 글을 붙여넣으면 제목·요약·소제목으로 정리한 보기 좋은 HTML 문서를 만들어 줍니다. 표나 흐름도도 알아서 그리고, "표로 정리해줘" 같은 요청을 덧붙일 수 있습니다. (대화 기능이 켜져 있어야 합니다)
- **번역** (`Ctrl + Shift + E`) — 복사해둔 글을 바로 번역합니다. 번역문을 먼저 보여주고, 복사 버튼을 눌러야 클립보드에 들어갑니다. (대화 기능이 켜져 있어야 합니다)
- **이미지 크기 바꾸기** (`Ctrl + Shift + R`) — 복사해둔 이미지를 0.5~4배로 키우거나 줄여 다시 복사해 줍니다. 픽셀 아트가 뭉개지지 않는 방식도 고를 수 있습니다.

## 음악·영상 조작

유튜브나 스포티파이 등에서 뭔가 재생 중이면, 펫 발밑에 이전곡·재생·일시정지·다음곡 버튼이 나타납니다.
크기·위치·투명도를 조절할 수 있고, 재생 중에 펫이 리듬을 타듯 고개를 끄덕이게 할 수도 있습니다. (기본 꺼짐)

## 색과 글꼴

- **말풍선 테마**: 차콜·로즈·오션·포레스트·앰버 5종, 또는 배경색·포인트색·글씨색을 직접 고르는 커스텀. 모든 창에 함께 적용됩니다.
- **글꼴**: 추천 글꼴이나 PC에 설치된 글꼴 중에서 고를 수 있습니다.
- **UI 크기와 글자 크기**를 따로 키울 수 있습니다.

- 우클릭 메뉴에 어떤 항목을 보여줄지도 설정창 **트레이** 탭에서 고를 수 있습니다.

## 설정 백업

설정창 **일반** 탭에서 설정 전체를 파일 하나로 내보내고 불러올 수 있습니다. PC를 바꿀 때 쓰세요.
보안상 **API 키는 백업에 포함되지 않으니** 새 PC에서 다시 입력해야 합니다.

설정·할일·기록은 `%APPDATA%\dangorobo` 폴더에 저장되며, 모두 이 PC 안에만 남습니다. (이름을 바꾸기 전부터 쓰던 PC라면 예전 폴더 `%APPDATA%\low-poly-desktop-pet`을 그대로 계속 씁니다.)

## 자주 묻는 것

**타이핑 내용을 훔쳐보는 건 아닌가요?**
아닙니다. 무엇을 눌렀는지는 저장하지 않고, 최근 몇 초 동안 몇 번 눌렸는지만 세서 꼬리 속도에 씁니다.

**펫이 클릭을 가로막나요?**
평소에는 클릭이 그대로 통과합니다. 말풍선이나 즐겨찾기 메뉴가 떠 있는 동안만 그 영역이 클릭을 받습니다.

**펫이 갑자기 사라졌어요.**
전체화면 방해 금지가 켜져 있으면 게임·발표 중에 잠시 숨습니다. 그 프로그램을 닫으면 다시 나타납니다. 우클릭 메뉴에서 직접 숨겼는지도 확인해 보세요.

**대화 기능이 안 켜져요.**
API 키를 먼저 입력해야 합니다. 무료 한도를 넘겼거나 키가 잘못됐으면 말풍선에 이유가 표시됩니다.

**Windows 시작할 때 자동으로 켜고 싶어요.**
우클릭 메뉴의 "Windows 시작 시 자동 실행"을 켜세요.

## 개발자용

소스에서 실행하거나 직접 빌드하려면:

```powershell
npm ci
npm start
npm run dist
```

작업 규칙은 [`AGENTS.md`](./AGENTS.md), 프로젝트 구조·기능별 구현 위치와 파츠·에셋 추가 절차는
[`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md)에 정리돼 있습니다.
