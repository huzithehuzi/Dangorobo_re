# Dangorobo 1.1.0

画面の片隅に住むレトロな雰囲気のデスクトップペットです。マウスを目で追い、タイピングに合わせて尻尾を振り、
なでると喜び、決めた時間になるとアラームで知らせてくれます。会話することもできます。

普段はクリックがそのまま透過するので、作業の邪魔になりません。Windows専用で、インストール不要の
実行ファイル1つで動きます。

## はじめに

1. 起動すると画面の隅にペットが現れ、タスクバーの通知領域にアイコンが表示されます。
2. ペットまたはトレイアイコンを**右クリック**するとメニューが開きます。設定画面もここから開けます。
3. ペットは**そのままドラッグ**して好きな場所に移動できます。位置は次回起動時にも保持されます。
4. 終了は右クリックメニューまたは `Ctrl + Shift + Q` です。

韓国語・英語・日本語に対応しており、初回起動時にWindowsの言語設定に合わせて自動的に選ばれます。

インストーラー(`Dangorobo-Setup.exe`)で導入した場合、新しいバージョンが出ると自動的に
ダウンロードし、再起動してインストールするか確認します。ポータブル版
(`Dangorobo-Portable.exe`)は更新確認を行わないため、新しいバージョンは手動でダウンロードして
ください。

## ペットの反応

- **マウスを目で追います。** カーソルの方向に頭を向けます。
- **タイピングに反応します。** 速く打つほど尻尾が大きく速く揺れます。何を打ったかは読まず、
  どれくらいの頻度で打ったかだけを見ています。
- **クリックやキー入力のたびに軽く縮みます。** ゼリーのように弾み、クリック時に音を鳴らすことも
  できます（初期設定はオフ）。
- **頭をなでてみてください。** 頭の上でマウスを左右にこすると、喜んで頭を下げます。
- **持ち上げると驚きます。** ドラッグしている間、手足をばたつかせます。
- **ひとりでいると眠ります。** 一定時間（初期設定は5分）入力がないと目を閉じてうとうとし、
  また動かすと目を覚まします。
- **放っておくと退屈します。** 見回す、伸びをする、手を振るといった動作を時々ひとりで行います。
- **Caps Lockがオンになると**教えてくれます（顔が驚いた表情で震えます）。
- **ゲームやプレゼン中は自動的に隠れます。** 全画面アプリを検知して、ペットとアラームを一時的に
  しまいます（有効化が必要）。

## カスタマイズ

設定画面の**カスタマイズ**タブで変更します。選ぶとすぐにペットへ反映され、保存せずに閉じると
元に戻ります。

- **色**：頭・胴体・耳・尻尾・手・頭飾り・目・口・顔の模様・顔の装飾・体の模様を、
  部位ごとに別々に色を塗れます。
- **パーツ**：耳5種（クマ・ウサギ・ネコ・キツネ・垂れ耳）、尻尾3種、頭飾り8種（リボン・チョーカー・
  メガネ・帽子・輪っかなど）。どのカテゴリも「なし」を選べます。
- **顔**：目・口の形と顔の模様・装飾を組み合わせます。表情は状況に応じて自動で変わります。
- **自分の顔絵を読み込む**：自作の表情画像をzipにまとめて読み込むと、既存の目・口の代わりに
  その絵が表示されます。
- **ペットの周りで色を選ぶ**：名前だけで選ぶのが難しければこのモードをオンにしましょう。ペットの
  横に部位ごとの色カードが実際の位置と線でつながって浮かび、見ながらすぐに選べます。
- **プリセット**：気に入った組み合わせに名前を付けて保存し、後でまとめて適用できます。サムネイル
  プレビューが表示され、ファイルとして書き出して別のPCで読み込むこともできます
  （初期状態でチェリー・ミロ・ロロの3種が入っています）。

## 画面エフェクト

設定画面の**外観**タブで調整します。気に入らなければ「外観を初期値にリセット」ボタンで一括で
元に戻せます。

- **サイズと尻尾の速さ**の調整
- **ピクセルアート**：強度を上げるとドット絵のような荒い見た目になります。
- **カラーパレット制限**：使う色数を減らしてレトロな雰囲気を出します。ウォーム・クール・
  モノクロ・ゲームボーイ風から選ぶか、好きな色で独自のグラデーションを作れます。
- **ディザリング**：色の境界を昔のゲームのようにドット模様で散らします（8種類）。
- **アウトライン**：シルエットに縁取りを描きます。色と太さを調整可能。
- **線の揺れ**：手描きアニメーションのように輪郭がわずかに揺れます。
- **照明**：光の色・強さ・方向を自分で調整できます。

## アラーム

設定画面の**アラーム**タブから複数登録できます。

- **繰り返し方法は4種類**：`N分ごと` / `正時ごと`（何時間ごとかを指定可能） /
  `毎日決まった時刻`（曜日指定も可能） / `N分後に1回だけ`
- `正時ごと`は登録した時刻に関係なく、**時計の正時（分・秒が0）**に鳴ります。
- アラームごとに**タイトルと本文**を個別に設定できます。
- 削除せずに**一時的にオン・オフ**したり、後から**内容を編集**することもできます。
- 時間になるとペットが万歳をして知らせ、確認するまで待ちます。
- 通知音は5種類から選ぶか、**アラームごとに好きなmp3・wavファイル**を指定できます。
- 「今すぐアラームをテスト」ボタンで見た目を事前に確認できます。
- 次のアラームまでの残り時間は右クリックメニューで確認できます。
- **天気ブリーフィング**：`毎日決まった時刻`のアラームで「天気ブリーフィングを含める」をオンに
  すると、鳴ったときに本文が今日・明日の午前/午後の天気(最高・最低気温、降水確率の4行)で
  自動的に埋まります(先に「一般」タブで地域を設定してください)。登録不要のOpen-Meteoで
  取得し、韓国国内の地域は気象庁(KMA)ベースのデータを優先的に使用します。トレイメニューの
  **現在の天気**でいつでも確認することもできます(トレイタブでオン・オフ可能)。

## 今日のToDoチェックリスト

`Ctrl + Shift + T` で開く小さなウィンドウです。

- やることを書いてチェックすると**ペットが祝ってくれます**。
- ドラッグで順番を入れ替えられ、残りの件数がバッジで表示されます。
- ウィンドウは好きな場所に置いてサイズ変更でき、閉じても状態がそのまま復元されます。

## お気に入りランチャー

よく使うプログラムをペットから直接起動します。プログラム・ショートカット・Webリンクを最大12個
登録でき、初期ショートカットは `Ctrl + Shift + F` です。

**表示方法は4種類から選べます。**

| 方式 | 表示のされ方 |
|---|---|
| ペットの吹き出し | ペットの頭の上にリストが表示されます（初期設定） |
| 移動可能なウィンドウ | 好きな場所に置ける小さなウィンドウ |
| フローティングボタン | 常に画面に表示される丸いボタン。押すと扇状に開きます |
| マウス位置に表示 | ショートカットを押したその場所に扇状メニューが出ます |

アイコンはプログラムから自動で取得され、気に入らなければ内蔵アイコン18種から選んで色を指定したり、
画像ファイルを直接指定することもできます。リスト表示・グリッド表示も切り替えられます。

## ペットと会話する

Googleの Gemini を使用します。**無料のAPIキーを自分で取得して入力する必要があり**、初期設定では
オフです。

1. 設定画面の**一般**タブでAPIキーを入力します（取得ページへのリンクが隣にあります）。
2. 会話機能をオンにして保存します。
3. `Ctrl + Shift + A` または右クリックメニューで会話ウィンドウを開きます。

- **性格を選べます**：気楽な友達、親しみやすい丁寧語、あっさりした相談役、軽いいたずらっ子、
  または自分で一行だけ指定。
- **呼び名**：ペットが自分をどう呼ぶか、自分自身を何と呼ぶかを決められます。
- 返答に合わせて**表情が変わり**、話している間は頭を縦に振ります。
- 質問した言語で返答します。
- **ペットから先に話しかけさせる**こともできます（3〜20分間隔）。長くなでるとそれに反応して
  話しかけさせたり、「呼ぶ」ボタンで直接呼びかけることもできます。
- **会話の効果音**：返答が1文字ずつ表示される際に、文字ごとに音が鳴ります。速さと音の高さを
  調整できます。
- **記憶機能**：オンにすると過去の会話を引き継いで記憶し、好みや習慣なども少しずつ覚えていきます。
  何を覚えているかは、「会話」タブの「'メモリー管理'タブを表示(上級ユーザー向け)」をオンにすると
  現れる設定画面の**記憶管理**タブで確認・削除できます。
- やり取りした内容は右クリックメニューの**質問・回答履歴**から検索・削除できます。

APIキーはWindowsのセキュアストレージに暗号化して保存され、設定のバックアップにも会話履歴にも
含まれません。

## 便利なツール

- **文書要約**（`Ctrl + Shift + D`）— 長い文章を貼り付けると、タイトル・要約・小見出しに整理された
  見やすいHTML文書を作成します。必要に応じて表やフローチャートも自動で描き、「表にまとめて」
  のような要望を追加することもできます。（会話機能をオンにする必要があります）
- **翻訳**（`Ctrl + Shift + E`）— コピーした文章をすぐに翻訳します。まず翻訳結果を表示し、
  コピーボタンを押して初めてクリップボードに入ります。（会話機能をオンにする必要があります）
- **画像サイズ変更**（`Ctrl + Shift + R`）— コピーした画像を0.5〜4倍に拡大・縮小して再度コピー
  します。ピクセルアートが崩れないモードも選べます。

## 音楽・動画コントロール

YouTubeやSpotifyなどで何か再生中の場合、ペットの足元に前へ・再生/一時停止・次へのボタンが表示
されます。サイズ・位置・透明度を調整でき、再生中にペットがリズムに合わせて頭を振るようにすることも
できます（初期設定はオフ）。

## 色とフォント

- **吹き出しテーマ**：チャコール・ローズ・オーシャン・フォレスト・アンバーの5種類、または背景色・
  アクセント色・文字色を自分で選ぶカスタムテーマ。すべてのウィンドウに一括で適用されます。
- **フォント**：おすすめフォントか、PCにインストールされているフォントから選べます。
- **UIサイズと文字サイズ**を個別に拡大できます。

## ショートカット

| 機能 | 初期ショートカット |
|---|---|
| ペットと会話 | `Ctrl + Shift + A` |
| お気に入り | `Ctrl + Shift + F` |
| チェックリスト | `Ctrl + Shift + T` |
| 文書要約 | `Ctrl + Shift + D` |
| 翻訳 | `Ctrl + Shift + E` |
| 画像サイズ変更 | `Ctrl + Shift + R` |
| 終了 | `Ctrl + Shift + Q` |

- 終了以外は**すべて好きな組み合わせに変更できます。** 設定画面の**ショートカット**タブでボタンを
  押し、使いたいキーを押すだけです（Ctrl・Alt・Shiftのいずれかを必ず含める必要があります）。
- 使わないショートカットは個別にオフにできます。他のプログラムが既に使用している組み合わせは、
  保存時に警告が表示されます。
- 右クリックメニューにどの項目を表示するかも設定画面の**トレイ**タブで選べます。

## 設定のバックアップ

設定画面の**一般**タブから設定全体を1つのファイルとして書き出し・読み込みできます。PCを買い替える
際に便利です。
セキュリティ上の理由から**APIキーはバックアップに含まれない**ため、新しいPCでは再度入力する
必要があります。

設定・ToDo・履歴は `%APPDATA%\dangorobo` フォルダに保存され、すべてこのPC内にのみ残ります。
（アプリ名の変更前から使っていたPCでは、以前のフォルダ `%APPDATA%\low-poly-desktop-pet` を
そのまま使い続けます。）

## よくある質問

**タイピング内容を盗み見ているのでは？**
いいえ。何のキーを押したかは一切保存せず、直近数秒間に何回打ったかだけを数えて尻尾の速さに
使っています。

**ペットがクリックを邪魔しますか？**
普段はクリックがそのまま透過します。吹き出しやお気に入りメニューが表示されている間だけ、その
領域がクリックを受け取ります。

**ペットが急に消えました。**
「全画面表示中はアラームを延期」がオンになっていると、ゲームやプレゼン中は一時的に隠れます。
そのプログラムを閉じると再び現れます。右クリックメニューから自分で非表示にしていないかも
確認してみてください。

**会話機能がオンになりません。**
先にAPIキーを入力する必要があります。無料枠を超えていたりキーが間違っている場合は、吹き出しに
理由が表示されます。

**Windows起動時に自動的に立ち上げたいです。**
右クリックメニューの「Windows起動時に自動実行」をオンにしてください。
