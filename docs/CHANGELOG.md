# 변경 이력

Dangorobo의 주요 마일스톤만 날짜별로 기록한다. 현재 구조·기능 계약·제약과 향후 과제는
[`DEVELOPMENT.md`](./DEVELOPMENT.md)를 기준으로 삼고, 세부 작업 과정은 Git 이력에서 확인한다.

## 2026-08-13

- **커서를 따라볼 때 몸통도 살짝 함께 돌게 함**: 머리만 돌아가서 몸은 늘 정면이었다.
  `animation-loop.ts`가 정한 최종 좌우 각도에서 `BODY_FOLLOW_RATIO`(0.18)만
  `modelRoot.rotation.y`로 넘기고 나머지를 머리에 남긴다 — 몸통에 각도를 **더하지 않고

  각도가 0.62rad을 넘어 목이 모델 한계까지 비틀린다). 최종 각도에서 파생하므로 아이들 루틴

  사라지면 함께 풀린다. 가로축만 준다 — 위아래·기울임까지 주면 발이 떠 보인다.
  `test/pet-animation-loop.test.js`에 3개를 더했고(비율 분담·가로축 전용·수면 시 복귀),
