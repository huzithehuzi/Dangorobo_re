- **즐겨찾기 아이콘·색상 선택 팝오버가 잘려서 못 고르던 문제를 고쳤다**: 원인이 둘이었다.
  (1) 팝오버가 카드 안의 `position: absolute`라 스크롤 패널과 형제 카드(그리드 아이템이라
  각자 스태킹 컨텍스트다)에 잘렸고, (2) 팝오버 안의 공용 색 선택기 호스트에 예전
  `<input type="color">` 시절의 `width/height: 26px`이 남아 있어서 펼친 색 패널이 그 26px
  상자를 넘쳐 클릭조차 못 했다. 팝오버를 네이티브 `popover`(최상위 레이어)로 바꾸고 색
  선택기 호스트를 `display: contents`로 풀었다. 최상위 레이어는 어떤 조상의 overflow·스태킹
  에도 잘리지 않고 바깥 클릭·Esc 닫기를 브라우저가 처리하므로, 카드에 z-index를 얹던 우회와
  위/아래 뒤집기를 재던 JS·문서 리스너가 함께 사라졌다. 버튼에 CSS anchor로 붙이는 방식은
  버렸다 — 앵커 아래 남은 공간으로 팝오버 높이가 깎여(fit-content가 inset에 제한된다) 색
  패널을 펼치면 다시 잘렸고 `position-try` 뒤집기도 걸리지 않았다. 화면 가운데에 띄워 창
  높이 전체를 쓰게 했다. `test/favorite-icon-picker-contract.test.js` 2개 추가, 변이로 확인했다.

- **외곽선 색상을 커스터마이징 프리셋으로 옮겼다**: 외형 탭에 있던 외곽선 색상 행을 커스터마이징

- **커스텀 얼굴·바디 이미지를 프리셋마다 따로 갖게 하고, 내보내기를 세트 파일로 바꿨다**:
